# VoleyEvents / court study

Open http://localhost:3001/sketches/002-court/index.html

Stance: a cobalt sports poster becomes a tactile court, with one large recognizable ball.

- Typography: monumental compressed phrasing, quiet project explanation below.
- Color: cobalt, chalk, chartreuse; court lines establish the physical surface.
- Interaction: drag-release the ball, click/keyboard Serve, repeat, reset. A bounded requestAnimationFrame simulation stops when the ball rests. Reduced motion uses immediate placements instead of flight.
- Strong at: immediate cause and effect, repeatability, recognizable subject, phone-friendly native Serve.
- Weak at: this is a 2D interaction/material sketch, not the requested finished cinematic Three.js rally. It does not validate a 3D camera, physical-phone GPU pacing or the complete case study.
- Deliberately rejected: miniature wireframe court stacks, long empty scroll runways, making the story contingent on playing.

Contacts count only actual toy court collisions in this page session; they are not product metrics. No backend operation occurs. Read the existing case-study route for actual project evidence/status.

Run `python3 sketches/verify.py` with the local server and dedicated CDP Chrome running.
