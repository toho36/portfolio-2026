The real system

“Looks right”
isn’t a release gate.

Goal Loop separates planning, independent critique, implementation, deterministic checks and review. A candidate passes only inside its declared boundaries. Otherwise it returns for a bounded repair—or stops.

Try adding a failing check. Watch the candidate come back instead of quietly turning green. The model simplifies the real system; its two-return limit is a demonstration setting, not a claim about every production run.
