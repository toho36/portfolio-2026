# Playable worlds / index study

Open http://localhost:3001/sketches/001-playable-worlds/index.html

Stance: a warm editorial index that previews distinctly themed worlds instead of hiding the work behind a manifesto.

- Typography: blunt oversized system sans, compact monospace labels.
- Color: chalk and vermilion; the active portal changes its material and palette.
- Interaction: native buttons or a range input select a world; bounded pointer tilt acknowledges exploration; the arrow opens the corresponding study or existing Playground.
- Strong at: immediate project visibility and distinct identities without a navigation game.
- Weak at: the selector alone is not a flagship technical showpiece. Each destination must earn its own interaction.
- Deliberately rejected: custom cursor, loader, fake dashboard, compulsory 3D navigation.

Disposable concept, not a replacement of the current app. The drawings are authored CSS/SVG, not finished WebGL evidence. Run `python3 sketches/verify.py` with the local server and dedicated CDP Chrome running.
