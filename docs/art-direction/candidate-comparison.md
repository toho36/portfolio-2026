## Approved synthesis

Use **A** for the whole-machine silhouette, **B** for modular construction, **C** for the slot interaction, and **D only** for reward timing. The owner selected this direction on 2026-08-05; no single generated image is a production asset.

## Production boundary

Project and critical copy stays real HTML/SVG. Geometry starts as procedural boxes, rails, cylinders, slots, gears and springs; generated imagery never pretends to be final 3D. No image-to-video layer returns.
