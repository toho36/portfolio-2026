# Goal Loop team-workflow candidate

Status: implemented in the isolated worktree and exercised by controller-owned browser verification. Independent reviewer verdicts are separate controller artifacts; this document does not manufacture review or release approval.

## What changed

The retired six-stop stepper is replaced by one asymmetric workbench. A translucent goal becomes a bounded plan, then a distinct solid candidate. Planner, Critic, Implementer, deterministic Check and independent Reviewer use anchored tools around that same material before the reducer issues Pass or Block. Check and Review visibly open different candidate layers; two vermilion repair tabs mirror the shared return budget.

The pure model owns all progress, returns, budgets and verdicts. Normal motion automatically advances to the next correction decision or terminal verdict. Reduced-motion and failed WebGL initialization switch to native one-step controls over the meaningful SVG artifact. Replay reuses the latest source/destination pose pair without reducer dispatch.

## Lifecycle boundary

Three and GSAP load only from the existing guarded loader sites. Server output contains the SVG and native controls but no canvas. The route controller invalidates pending generations and callbacks, pauses for Escape/visibility/offscreen changes, settles and pauses on resize, and disposes its observer, listeners, timeline, canvas and renderer resources on teardown. Idle and stable poses render once; no route-local request-animation-frame loop runs.

Geometry evidence is exposed on `.run-instrument` as projected renderer values: `data-artifact-px`, `data-machine-height-px`, and artifact edge attributes. Static mode measures the drawn SVG artifact and machine independently. These attributes support browser acceptance but do not replace painted visibility review.

## Evidence boundary

Automated unit, immutable contract, type, production-build, source-closure, loader, style, history and route checks establish the tested implementation boundaries. The controller ran the actual Python browser harness against the worktree production preview at `http://127.0.0.1:4178`, not the primary checkout. It passed 20 route/viewport layouts with no page or console errors, including native click, keyboard and emulated-touch interactions, both return sources, bounded unchanged retries, replay restoration, reduced-motion and unavailable-WebGL paths.

An additional controller matrix captured 28 desktop/mobile state screenshots and checked the current artifact bounds, mobile action placement and artifact/control separation. A separate owned-browser test observed real visible-to-hidden-to-visible tab transitions: no additional WebGL draws or stage progress while hidden, followed by explicit Resume to Pass. The persistent-browser driver could not reliably establish native hidden state; those failed probe attempts are retained rather than counted as product evidence.

A targeted Chrome sample recorded a 2 ms DOM acknowledgement, no interaction long tasks, no idle draw calls and no console errors in the WebGL-unavailable fallback. These are local lab observations, not physical-phone GPU or production metrics. Physical-phone behavior, human three-second comprehension and subjective visual preference remain unverified. The sculpture is a renderer-native illustration, not image-generated media or a live agent system.
